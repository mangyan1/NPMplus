What this fork adds

The proxy-manager experience stays familiar. The extra work is around installation, visibility, and recovery.

  • Guided installationChecks the host, installs the stack, and asks before important system changes.
  • Security overviewBrings CrowdSec, Anubis, local attack activity, and service health into one useful view.
  • Cleaner CrowdSec dataKeeps CAPI protection active while showing the local events that matter to this proxy.
  • Recoverable updatesTakes a last-good snapshot, checks health after updating, and rolls back a failed state.
  • Routine backupsAutomates daily data backups and keeps a bounded recovery history.
  • Boot diagnosticsWaits for usable DNS and provides a trace report when startup does not go to plan.

Request path: internet traffic is checked by CrowdSec and Anubis, routed through NPMplus, then passed to your application.

Install from a clean server

Use Debian 12/13 or Ubuntu 22.04+. You can inspect the script on GitHub before running it.

wget -qO setup-npmplus.sh \
  https://raw.githubusercontent.com/mangyan1/NPMplus/develop/setup-npmplus.sh &&
sudo bash setup-npmplus.sh

The installer explains its choices and asks before making important changes.
