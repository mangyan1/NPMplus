A one-command installer checks the host and asks before important changes.

06Boot diagnostics

Startup checks and trace tooling make DNS or container delays easier to diagnose.

One paste installation

Start from a clean server.

Use Debian 12/13 or Ubuntu 22.04+, with ports 80 and 443 available. Read the script before running it if you prefer.

See requirements and the beginner guide →

wget -qO setup-npmplus.sh https://raw.githubusercontent.com/mangyan1/NPMplus/develop/setup-npmplus.sh &&
sudo bash setup-npmplus.sh

The installer explains its choices and asks before making important system changes.
